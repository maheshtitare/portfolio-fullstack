# Personal Portfolio (Full Stack Project)

##  Overview

This is a full stack personal portfolio project developed using modern web technologies.
It showcases my skills, projects, and provides a way to connect with me.

##  Tech Stack

* Frontend: HTML, CSS, JavaScript, React.js
* Backend: Java, Spring Boot
* Database: MySQL
* Tools: Git, GitHub, VS Code

##  Features

* Responsive portfolio design
* Projects showcase section
* Contact form (backend integrated)
* REST APIs for handling data
* Clean UI and user-friendly interface

## How to Run

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
mvn spring-boot:run
```
